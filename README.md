# صوتيات | Sawtiyat

تطبيق Android أصلي لقراءة الكتب والنصوص العربية صوتيًا، مع تخزين محلي وعدم اشتراط حساب أو خادم لتشغيل القراءة.

## الحالة الحالية
يتضمن الإصدار الحالي (0.2.0):
- واجهة عربية RTL بهوية بنفسجية وذهبية.
- مكتبة محلية عبر Room تعرض ملخصات الكتب دون تحميل كامل المحتوى إلى قائمة المكتبة.
- استيراد TXT وPDF وEPUB مع حدود أحجام آمنة ورسالة واضحة عند عدم وجود نص قابل للاستخراج من PDF.
- إضافة نص يدوي.
- تطبيع محافظ للأرقام العربية/الهندية والهواتف والنسب المئوية والتواريخ والأوقات والعملات والوحدات قبل TTS.
- خدمة قراءة أمامية تقرأ مقطعًا منطقيًا في كل مرة، وتحفظ التقدم في موضع النص الأصلي.
- عناصر تحكم الإيقاف المؤقت والاستئناف والإيقاف من إشعار التشغيل، وسرعات 0.75× إلى 2×.
- اختبارات JUnit لمعالجة الأرقام وبعض الصيغ الشائعة.

هذا إصدار تجريبي محسّن، وليس بعدُ الإصدار النهائي الذي يحقق كامل المواصفات.

## متطلبات البناء
- Android Studio حديث.
- JDK 17.
- Android SDK Platform 35.
- Gradle 8.9 أو أحدث متوافق مع Android Gradle Plugin 8.7.3.

## البناء
من مجلد المشروع:
```bash
gradle assembleDebug
```
أو افتح المشروع في Android Studio ثم اختر Build > Build Bundle(s) / APK(s) > Build APK(s).

الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## تثبيت
فعّل السماح بتثبيت التطبيقات من المصدر الذي تستخدمه، ثم ثبّت APK الناتج.

## ملاحظات مهمة
- محرك Android TTS قد يستخدم صوتاً محلياً أو صوتاً يتطلب تنزيل بياناته. من إعدادات تحويل النص إلى كلام في Android تأكد من تنزيل صوت عربي يعمل دون إنترنت.
- لا تتضمن النسخة نموذجًا عربيًا مستقلًا من sherpa-onnx أو Piper؛ جودة الصوت وتوفّره دون إنترنت يعتمدان على المحرك والصوت المثبتين في الجهاز.
- تطبيع الأرقام تقريبي ومحايد للسياق، ولا يحل محل محلل صرفي/نحوي عربي ولا يضمن النطق الصحيح لكل سياق أو لهجة. لا توجد حاليًا حزمة اختبار مسموعة أو مراجعة بشرية للنطق.
- OCR العربي، محرر قاموس النطق، مزامنة النص والصوت الدقيقة، MediaSession وأزرار شاشة القفل، إدارة الفصول والنسخ الاحتياطي ضمن مراحل لاحقة.
- لا ندعي دعم اللهجة الحضرمية أو جودة صوت احترافية قبل اختبار نموذج فعلي ومراجعته على أجهزة ومتحدثين.
- لا توجد مفاتيح API أو خدمات سحابية في النسخة الحالية.
- راجع `THIRD_PARTY_NOTICES.md` قبل أي توزيع.
