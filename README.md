# صوتيات | Sawtiyat

مشروع Android أصلي أولي لتطبيق قراءة الكتب وتحويل النص إلى كلام محلياً.

## الحالة الحالية
هذه نسخة تأسيسية قابلة للبناء والتطوير، وليست بعدُ إصداراً نهائياً مكتملاً بكل خصائص الوثيقة:
- واجهة عربية RTL بهوية بنفسجية وذهبية.
- مكتبة محلية باستخدام Room.
- استيراد TXT وPDF وEPUB.
- إضافة نص يدوي.
- قراءة النص عبر Android TextToSpeech محلياً (يعتمد توفر صوت اللغة على الجهاز).
- حفظ الكتب وموضع القراءة محلياً.
- تشغيل القراءة من خدمة أمامية مخصصة.

## متطلبات البناء
- Android Studio حديث.
- JDK 17.
- Android SDK Platform 35.
- Gradle 8.9 أو أحدث متوافق مع Android Gradle Plugin 8.7.3.

## البناء
من مجلد المشروع:
```bash
gradle assembleDebug
```
أو افتح المشروع في Android Studio ثم اختر Build > Build Bundle(s) / APK(s) > Build APK(s).

الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## تثبيت
فعّل السماح بتثبيت التطبيقات من المصدر الذي تستخدمه، ثم ثبّت APK الناتج.

## ملاحظات مهمة
- محرك Android TTS قد يستخدم صوتاً محلياً أو صوتاً يتطلب تنزيل بياناته. من إعدادات تحويل النص إلى كلام في Android تأكد من تنزيل صوت عربي يعمل دون إنترنت.
- هذه النسخة لا تتضمن بعد sherpa-onnx أو نموذج Piper مدمجاً. أُبقيت طبقة المحرك قابلة للتوسعة حتى يتم اختبار نموذج عربي محدد وترخيصه وحجمه قبل إضافته.
- OCR العربي، مزامنة الأجهزة، محرر قاموس النطق، مزامنة النص والصوت الدقيقة، وإدارة النطاقات المتقدمة ضمن مراحل التطوير التالية.
- لا توجد مفاتيح API أو خدمات سحابية في النسخة الحالية.
- راجع `THIRD_PARTY_NOTICES.md` قبل أي توزيع.

## GitHub Actions
الملف `.github/workflows/android.yml` يبني APK Debug تلقائياً عند الدفع إلى GitHub، ويرفعه كـ workflow artifact.
